{\ttfamily YAMLTree\+Handle} wraps {\ttfamily ryml::\+\+Tree} into C objects so they can be part of a shared object library to interface with other languages

{\ttfamily ryml::\+\+Tree}s are stored in memory simply as arrays. {\ttfamily ryml::\+\+Node\+Ref} acts as a simple wrapper around nodes, which are just indices in the tree array. Trees are obtained by parsing C++ std::\+string, and values are simply pointers to locations in the string. Therefore, the string must be kept in memory as long as the tree is in use.

The program {\ttfamily get\+\_\+lattices} will create a struct containing three lattices:\+
\begin{DoxyItemize}
\item {\ttfamily original} is a map containing the base lattice as well as any lattices included in the base lattice.
\item {\ttfamily included} is the base lattice but with all included files substituted in.
\item {\ttfamily expanded} is the base lattice after lattice expansion has been performed. Specify the lattice file with the first argument to the function. On default, the lattice specified by the last {\ttfamily use} statement will be used, and if no {\ttfamily use} statement exists, the lattice lattice in the file will be used.
